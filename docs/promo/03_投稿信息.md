## 简介

```
一个给欧陆风云 5 模组作者用的侧边栏工具：填名称、选修正，脚本和本地化自动生成，还能直接写进 MOD。

■ 五类内容
革新 / 决议 / 事件 / 特权 / 法律，名称、描述、修正一填，脚本和 l_simp_chinese 一起出。

■ 修正库
读你本机的原版 + DLC + MOD，三千多条修正带中文名（比如「骑马旗本武士招募花费」），按国家 / 地点 / 角色分类，标了百分比与开关，MOD 自带的会打 MOD 徽章。

■ 革新前置
「接在哪个革新之后」直接打中文名搜索，可多选；MOD 新加的革新也能选到。

■ AI 助手
用中文描述需求，自动填 potential / allow / effect，不用记触发器名字。

■ 写入 MOD
新建文档或选已有文档追加：脚本按 id 去重、本地化按 key 去重，自动补 UTF-8 BOM。

■ 编辑旧条目
选一条已有条目：本地化在上、数据在下，时代 / 图标 / 限制 / 修正逐项小框修改，只回填动过的字段，注释原样保留。

■ 多数据源
可以同时挂多个 MOD 路径，MOD 新增的时代也会出现在时代下拉里。

开源、MIT：
https://github.com/fjoasiw/pdx-forge

问题或想要的功能，评论区 / Issues 都可以提。
```
