# 录制清单

录之前照着打勾，能省掉大部分返工。

## 一、开录前的准备

- [ ] 重启一次 DSH 桌面端（插件更新过 Host 时必须重启）
- [ ] 左侧栏能看到「PDX 模改工坊」图标；点开后顶部显示 `修正 3000+ 条 · 革新 5000+ 条`
- [ ] 「数据源」页确认有两条：`原版`（游戏目录）+ 你的 MOD 根目录，且都显示计数
- [ ] 设置里已选好**默认模型**（AI 演示要用；没配的话那一段会报错）
- [ ] 准备一个**测试用 MOD 目录**（复制一份或用 git 分支），演示写入会真的改文件
- [ ] 想好 1–2 个演示用 ID，例如 `demo_advance`、`demo_decision`，别现场纠结命名
- [ ] 关掉 QQ/微信弹窗、浏览器书签栏，桌面图标收干净
- [ ] 演示用的「已有文档」先建好一个（如 `in_game/common/decisions/demo_pack.txt`），里面放一条无关条目，这样「追加不覆盖」看得清楚

## 二、录像设置

| 项目 | 建议 |
|---|---|
| 分辨率 | 1920×1080，60fps（打字段更顺滑） |
| 工具 | OBS「显示器采集」或 Win+G |
| 缩放 | 浏览器/客户端缩放 100%；若面板字太小，调到 110–125%，别超过 125% 否则右侧代码换行 |
| 鼠标 | 打开「高亮点击」或后期加点击音效 |
| 录音 | 先单独录口播（手机/耳麦都行），再对画面 |

## 三、逐段录制顺序（可分开录，后期拼）

**第 1 段 · 痛点（约 15 秒）**
1. 进游戏大地图，慢推 2 秒
2. 切到编辑器，打开一个真实的革新脚本，滚轮快速下滚
3. 特写一行写错的括号 / 或控制台报错

**第 2 段 · 引出（约 10 秒）**
4. 切回 DSH，鼠标从左侧栏滑到新图标 → 点击 → 面板展开（停 1 秒再动）

**第 3 段 · 革新（约 30 秒）**
5. 填 ID `demo_advance` → 名称「演示革新」→ 描述一句话
6. 时代选「文艺复兴」
7. 「接在哪些革新之后」输入「封建」→ 停 0.5 秒让列表出来 → 点「封建制度」
8. 修正区选「每月威望」填 `0.5`；再选「陆军士气」填 `5%`
9. 鼠标划过右侧生成的脚本（停 1 秒）

**第 4 段 · 修正库（约 20 秒）**
10. 切分类：国家 → 地点 → 角色，各停 0.5 秒
11. 展开子类（阶层 / 军事 / 经济）
12. 搜一个你 MOD 里自建的修正，指一下 `MOD` 徽章

**第 5 段 · AI（约 20 秒）**
13. 切「决议」标签
14. AI 助手里输入：「只有和平时期可用，花费 100 金币换 50 威望」
15. 点「AI 生成触发与效果」→ 等结果 → 填好后停 1 秒
16. 鼠标划过 potential / effect 两栏

**第 6 段 · 写入（约 20 秒）**
17. 点「写入 MOD」→ 点右侧 ▾ 展开
18. 「脚本文件」点「浏览…」→ 在弹窗里选 `demo_pack.txt`（⚠️ 会弹出系统文件对话框，录进去很有说服力）
19. 本地化保持「新建」
20. 点写入 → 等「已写入」提示 → 打开该文件，滚到新增条目，展示 BOM 没乱

**第 7 段 · 编辑旧条目（约 20 秒）**
21. 展开「编辑已有条目」→ 搜「演示」→ 选中刚才那条
22. 先展示**本地化**区块（名称/描述一行一个输入框）
23. 往下滚到**数据**区块：改时代下拉、改一条修正的数值
24. 保存 → 展示「已保存」；如需展示原样保留，展开「高级 · 原始脚本」看注释还在

**第 8 段 · 数据源（约 10 秒）**
25. 进「数据源」页，指着两条路径与计数
26. （可选）加一个另一个 MOD 路径 → 立即扫描 → 展示每个源各自计数

**第 9 段 · 收尾**
27. 片尾卡 + GitHub 页面（浏览器打开仓库首页，慢推 2 秒）

## 四、容易翻车的点

- **AI 那段**：如果模型没配好会返回错误，先单独点一次确认能出结果再开录。
- **写入演示**：会真的改测试 MOD 的文件，建议用副本；录完把测试文件删掉或 git checkout。
- **文件对话框**：会弹到最前面，OBS 采显示器的话能录到；若用窗口采集，记得切到全屏采集。
- **浏览器缩放**：125% 以上右侧代码会换行，观感差。
- **长时间静置**：面板 60 秒会重扫一次数据，别让画面空着超过 1 分钟。
